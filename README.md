# Blooming Hives — Next.js

A runnable Next.js project containing the latest Blooming Hives website preview,
including the brand-logo section. The full original HTML is kept in
`public/blooming-hives.html`, preserving its CSS, animations, interactions,
and embedded logo images.

## Requirements
- Node.js 20 LTS recommended (18.18+ supported)
- npm

## Run on Windows

1. Extract this ZIP.
2. Open the extracted `blooming-hives-nextjs-final` folder in VS Code.
3. Open Terminal in that folder.
4. Run:

   ```bash
   npm install
   npm run dev
   ```

5. Open http://localhost:3000 in your browser.

## Production

```bash
npm run build
npm start
```

## Project structure

- `app/page.tsx` — Next.js home page
- `app/layout.tsx` — metadata and root layout
- `app/globals.css` — full-screen website frame
- `public/blooming-hives.html` — complete website HTML, scripts, styles and embedded logos

To edit the website's design and interactions, edit `public/blooming-hives.html`.
